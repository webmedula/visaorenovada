# Autoavaliação Visual Inteligente (Bônus 2)

App React/Vite criado no Lovable (repositório original: `webmedula/olhos-saudaveis-ai`) e incorporado aqui.
É servido em `app.visaorenovada.com.br/avaliacao/` pelo mesmo container do app de exercícios
(veja `services/app/Dockerfile`).

Desenvolvimento local:

```sh
npm ci
npm run dev      # http://localhost:8080/avaliacao/
npm run build    # gera dist/
```
